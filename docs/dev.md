# Подход при разработке

Код прототипировался с применением Codex + Pi Agent (GLM 5.3).

Не стал использовать какой-то подход с описанием спеки типо Spec Driven Development ввиду того, что, на мой взгляд, это более применимая к продуктовоой разработке история, у меня же не было чётких бизнес-требований.
