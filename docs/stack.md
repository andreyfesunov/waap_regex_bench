# Технический стек

В качестве языка для задания рассматривался Go и Rust - изначально склонялся к Rust, ибо, казалось, что есть готовые либы для работы с hyperscan и другими библиотеками, но они в большинстве своём давно не поддерживаются, потому был выбран Go + CGO для работы с либами (кроме того, был обнаружен относительно свежий [пакет](https://github.com/flier/gohs) для работы с Hyperscan, что для конкретной библиотеки упразднило работу с CGO). Кроме того, у разработика банально больше опыта в Go.
