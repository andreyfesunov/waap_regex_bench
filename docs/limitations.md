# Ограничения системы

Почему система не смогла бы сейчас обрабатывать 100М или 1B запросов:

1. Работа с памятью. Сейчас всё грузим в RAM, ибо объём датасета позволяет. С бОльшим датасетом (условно, 100M - 482 ГБ, 1B - 4.82 ТБ) надо работать батчами - читать, нормалзиоавть, обрабатывать ограченными кускаи, осовбождать их после обработки.
2. Все результаты копятся в RAM - в текущей реализации записываем только тогда, когда полностью закончили работу. Надо записывать результаты по мере поступления.
3. Большое количество объектов, нагрузка на GC - потенциально переиспользовать буферы, использовать sync.Pool.
4. Сбой спустя часы потребует повторного запуска - требуется fault tolerance доработка, нужно научить систему восстанавливаться.
5. Увеличение числа воркеров не даст ускорения на одной машине - потенциально надо будет горизонтально масштабироваться.
6. JSONL на миллиард запросов может занимать большой объём диска. Решение - партиционирование.
