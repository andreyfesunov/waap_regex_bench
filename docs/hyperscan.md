# Как и почему это работает

- Hyperscan требует много времени для прекомпиляции всех выражений в одну базу.
- У нас одно обращение к движку вместо K, где K - количество выражений. Это, конечно, не даёт асимптотику вида O(L), L - длина запроса, скорость непременно зависит от сложности выражений, размера базы. Но количество выражений != напрямую столько же отдельных проходов по запросу.
